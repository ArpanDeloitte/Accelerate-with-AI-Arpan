============================================================
  QueryGenie  -  SETUP GUIDE
============================================================

QueryGenie is a visual generator for Oracle ODI Knowledge-Module
style SQL (INSERT / MERGE, nested outer-join subqueries, derived
sources, column transforms, and more). It runs entirely on YOUR
machine. Nothing is sent anywhere except (optionally) to your own
Anthropic API key when you use the AI features.

Follow the sections in order. If you only want to build SQL and
copy it out, you do NOT need Python at all - see "OPTION A".


============================================================
 STEP 1 - CHECK IF PYTHON IS INSTALLED  (needed for the web app
          and Live DB; NOT needed for OPTION A below)
============================================================

QueryGenie's web server and Live-DB bridge need Python 3.9 or
newer. First check whether you already have it:

 1. Open a Command Prompt:
      - Press the Windows key, type  cmd  and press Enter.
        (or press Win+R, type  cmd , press Enter)

 2. In the black window, type this and press Enter:

        python --version

 3. Read the result:
      - If it prints  "Python 3.9.x"  (or 3.10 / 3.11 / 3.12 /
        higher) -> GOOD. Python is installed. Skip to STEP 3.
      - If it prints  "Python 3.8.x" or lower -> too old, do STEP 2.
      - If it says  'python' is not recognized...  -> not installed,
        do STEP 2.
      - If a Microsoft Store page opens instead of a version ->
        Python is not really installed; do STEP 2.

    (Tip: if  python  does nothing, also try:   py --version )


============================================================
 STEP 2 - INSTALL PYTHON  (only if STEP 1 said it is missing/old)
============================================================

 1. Open a browser and go to:

        https://www.python.org/downloads/

 2. Click the big yellow  "Download Python 3.x.x"  button
    (this gives the 64-bit Windows installer).

 3. Run the downloaded file (e.g. python-3.12.x-amd64.exe).

 4. IMPORTANT - on the FIRST installer screen, at the BOTTOM,
    TICK the box:

        [x] Add python.exe to PATH

    Then click  "Install Now"  and let it finish.
    (If it offers "Disable path length limit" at the end, click it.)

 5. Close the installer. Then open a NEW Command Prompt (the old
    one won't see the change) and verify:

        python --version

    It should now print  Python 3.12.x  (or similar). Done.

 --- No admin rights on your machine? ---
   - The python.org installer works per-user without admin - just
     leave the default "Install Now" (it installs for you only).
   - OR install "Python 3.x" from the Microsoft Store (search
     "Python" in the Store app). After installing, verify with
     python --version in a new Command Prompt.
   - OR ask your IT team to enable Python via your software portal
     (Company Portal / Software Center).


============================================================
 OPTION A - QUICKEST: build & copy SQL only  (NO Python needed)
============================================================

 1. Double-click  index.html  -> it opens in your browser.
 2. Build your mapping (see "USING THE APP" below) and click
    Copy SQL or Download .sql.

 That's it. AI (NL Query) and Live DB are NOT available in this
 mode - for those, use OPTION B.


============================================================
 OPTION B - RUN THE WEB APP  (enables AI / NL Query + voice)
            needs Python 3.9+  (STEP 1-2 above)
============================================================

 1. Double-click  QueryGenie-Web.bat
 2. The FIRST run installs the needed Python packages automatically
    (this takes a minute; needs internet once). You will then see:

        Uvicorn running on http://127.0.0.1:8000

    and your browser opens at  http://localhost:8000
 3. KEEP that black window open while you use the app.
    Close the window to stop the app.
 4. (Optional) NL Query: click  NL Query , paste YOUR OWN Anthropic
    API key and click Connect - or click "Try demo mode" to explore
    offline. The key is kept for the session only and never saved.


============================================================
 OPTION C - LIVE DB: browse your own Oracle tables
            needs Python 3.9+  (STEP 1-2 above)
============================================================

 1. Double-click  start-bridge.bat
 2. The FIRST run does two things (needs internet once):
      - installs the Python packages, and
      - downloads Oracle Instant Client (~60 MB) from Oracle's
        official site. This lets auto-login / SSO Autonomous DB
        wallets connect with NO wallet password ("thick mode"),
        exactly like SQL Developer.
    It then prints:   DB bridge -> http://localhost:8788
    KEEP THAT WINDOW OPEN.

 3. In the app (running from OPTION B, or open index.html):
      Source Tables  ->  click  "Live DB"  ->  Database Connections
      A green dot means the bridge is connected; red means it's
      offline (demo connections still work either way).
      - Cloud Wallet (Autonomous DB): enter YOUR DB Username /
        Password, then Upload YOUR wallet .zip and pick the Service.
        No wallet password is needed - the bundled Instant Client
        opens the auto-login wallet automatically, like SQL Developer.
        Click  Connect & Save.
      - Basic (host / port): enter YOUR DB Username / Password, then
        Hostname, Port, and Service name / SID. Click  Connect & Save.

 4. Click your saved connection to browse its tables / columns and
    add them as sources. Or skip the browser entirely: on any Source
    Table, set  Source Type = Live DB  and type the table name directly -
    it will autosuggest real tables from your connection(s).

 --- If the Instant Client download is blocked by your network ---
   The bridge still runs. Two options:
     a) Host/port connections and password-protected wallets work
        without Instant Client (thin mode).
     b) For auto-login SSO wallets, copy the  instantclient  folder
        out of  QueryGenie.zip  into THIS folder, then re-run
        start-bridge.bat.

 --- If Live DB fails with an Instant Client / DLL error ---
   Install the Microsoft Visual C++ Redistributable (x64) from
   Microsoft, then re-run start-bridge.bat. (Most Windows PCs
   already have it.)


============================================================
 USING THE APP  (build ODI-KM-style SQL)
============================================================

 1. Set the Target (Schema + Table) and an output mode:
    Plain SQL / INSERT / MERGE / Procedure.
    - If the Target Schema matches a database you connected under
      Live DB (see OPTION C), the Table Name auto-suggests real
      tables, and once you pick/type a real one, its actual columns
      are pulled in and the Column Mappings grid rebuilds to match
      them exactly - so your INSERT column list mirrors the real
      target table. If the schema isn't found live, Target Table
      stays completely free text, as before.
 2. Add Source Tables (base tables) and/or Subquery Sources
    (a subquery in the FROM/JOIN). Both take a Schema + Table name.
    Each one has a  Source Type  dropdown:
      - Choose source type : type any table name freely (Fusion KB
                           suggestions still appear as you type).
      - Live DB          : the Table field suggests real tables from
                           ALL your connected Live DB connections;
                           Platform locks to Oracle automatically.
      - Oracle source    : suggests from the built-in Oracle Fusion
                           demo catalog; Platform also locks to Oracle.
 3. Define Joins, Filters, Group By, and Window functions.
 4. Column Mappings: click  Smart Auto-Map  to auto-fill target
    columns from ALL sources (base AND derived), or map manually.
    (Load each source's columns first: "Auto-Load Columns" on a
    base source, or "Load Columns" on a derived source - this works
    for Live DB tables too, once Source Type = Live DB.)
 5. Review the live SQL on the right, then Copy SQL / Download .sql.
    Flip  Auto / Manual  above the SQL panel to hand-edit the
    generated SQL yourself: Auto is live-generated and read-only;
    Manual makes it an editable text box (seeded from the current
    SQL) that Copy / Download both use as-is.
    Switching back to Auto regenerates fresh from the builder.


============================================================
 TYPICAL SETUP = two windows open
============================================================
   Window 1: QueryGenie-Web.bat   (the app,   http://localhost:8000)
   Window 2: start-bridge.bat     (Live DB,   http://localhost:8788)
 Close both windows to stop everything.


============================================================
 FILES IN THIS FOLDER
============================================================
  index.html               The app UI shell (loads qg-app.min.js)
  qg-app.min.js            The app's JavaScript bundle (all logic)
  app.py                   The Live-DB bridge (runs locally)
  web_app.py               Local web server for the app
  QueryGenie-Web.bat       >> double-click to start the web app
  start-bridge.bat         >> double-click to start Live DB
  requirements.txt         Python dependencies (auto-installed)
  sonar-project.properties SonarQube analysis configuration
  .gitignore               Keeps local-only files out of git
  setup.txt                this file

 This repository is a FLAT set of files (no subfolders). The first
 time you run start-bridge.bat it creates local-only folders here at
 runtime - instantclient/ (the driver), connections/ and
 connections.json (your saved DB logins/wallet), and .staging/.
 These are git-ignored and hold secrets: NEVER commit or upload
 them. You can delete them any time; they are recreated on next run.


============================================================
 TROUBLESHOOTING
============================================================
  "'python' is not recognized"        -> do STEP 1-2 (install
                                          Python, tick Add to PATH),
                                          then open a NEW Command
                                          Prompt.
  Port 8000 already in use             -> another app uses it. Close
                                          it, or run:
                                          python -m uvicorn web_app:app
                                          --port 8001
  The .bat opens as text / won't run   -> make sure the file still
                                          ends in .bat and Python is
                                          on PATH (STEP 1).
  Live DB says "bridge offline"        -> start start-bridge.bat and
                                          keep its window open, then
                                          click the status dot in
                                          Database Connections to
                                          re-check.
  ModuleNotFoundError on startup       -> let the .bat finish its
                                          first-run install, or run:
                                          pip install -r requirements.txt


============================================================
 PRIVACY & SECURITY
============================================================
 - SQL generation runs entirely in your browser; no source data
   leaves your machine.
 - If you use AI features, requests go only to YOUR own Anthropic
   API key; the key lives in the browser session and is never stored.
 - The Live-DB bridge binds to 127.0.0.1 only and is read-only.
   Uploaded connection names and wallet archives are validated to
   stay inside the bridge's own folder (path-traversal / zip-slip
   safe); credentials never leave your machine.
